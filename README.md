# Нелинейная модель двигателя — лабораторная работа №1 по ТАУ

Исследование нелинейной модели двигателя: как он ведёт себя при разном напряжении и что меняется при добавлении вязкого трения. В работе сняты и сохранены данные для трёх режимов, так что результаты можно сравнивать между собой и пересчитывать заново прямо в Simulink.

## Режимы, для которых собраны данные

- напряжение 5 В
- напряжение 10 В
- работа при наличии вязкого трения

## Структура

| Файл / папка | Назначение |
|--------------|------------|
| `Engine.slx` | Основная модель двигателя в Simulink |
| `activation.m` | Скрипт активации и расчёта |
| `signal.mat` | Сохранённые данные сигналов |
| `models/` | Дополнительные модели |
| `resources/project/` | Ресурсы проекта |
| `L1_ENGINE.prj` | Файл проекта MATLAB |
